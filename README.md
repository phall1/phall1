I build at the seam between people, agents, and machines: terminals as programmable infrastructure, local-first instrumentation, coding-agent workflows, and low-level systems software. Most of it is written in Rust, Zig, Go, or TypeScript. All of it starts with a real problem.

What you will find here:

- **Terminal-native tools** that treat the terminal as an API, not a pile of pixels.
- **Agent infrastructure** for giving coding agents better environments, context, and control.
- **Small systems with sharp edges**: compilers, network tooling, native apps, and TUIs.
- **Working experiments** that are built in public and occasionally escape the lab.

## Start here

### [phux](https://github.com/phall1/phux) / the terminal control plane

A terminal multiplexer where a terminal is a first-class object on a wire. Humans, TUIs, GUIs, and agents can all hold the same live terminal instead of passing screenshots and copied text around.
